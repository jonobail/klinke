## Signal flow (as built)

- `send → 15 kHz LPF → (+ feedback) → tanh overload (ADC full scale) → REPEAT gate → memory`; with
  REPEAT the memory loops through a 16384 / 41000 s DelayNode (whole samples, so the loop doesn't
  dull) and nothing new is written.
- **DELAY ONLY** (extra `dly` jack): memory → DelayNode (switch delay) → 15 kHz LPF. Its feedback pot
  and the MAIN one are summed → EQ LOW (low shelf 250 Hz) → EQ HI (high shelf 3 kHz) → input.
- **MAIN** (`out`), by FUNCTION:
  - NORMAL / EXTEND / REVERSE / µPC#/b: two DelayNodes driven by a looped ramp (the pointer), OUTB half
    a window from OUTA, crossfaded by WaveShaper splice curves from the same ramp. The pointer drifts
    at |1 − ratio| s/s (REVERSE: 1 + ratio, reading backwards), so it wraps |drift| / window times a
    second. Window 25 ms. Base delay = MAIN 50 / 100 / 200 switches.
  - FLANGE: one DelayNode swept by a triangle 7.5–17.5 ms at the SSB slope (f / 82 kHz), plus the
    fixed delay at 12.5 ms inverted.
  - RANDOM: one DelayNode at 12.5 ms wandering on smoothed noise.
  - DELAY: the fixed delay at the full MAIN setting.
- MANUAL is the pitch pot: ratio = 0.25 + 1.75 × knob in the VCO modes, 1 ± f / 82 kHz in the SSB ones.
  The readout shows the ratio (the sweep ratio in FLANGE / RANDOM), the function, and both delays.

## Interpretation

- **ALGORITHM 1 / 2** aren't described beyond "splicing ramps" (RAMP FLAG starts ALGORITHM 2's): ALG 2
  is a continuous raised-cosine crossfade; ALG 1 holds one pointer and hands over in the last / first
  10 % of each cycle. ALG 1's extra low-level delayed signal in FLANGE / RANDOM isn't modelled.
- **EXTEND** and **REVERSE** windows: 50 ms (twice NORMAL's). REVERSE reads each window backwards.
- FLANGE's "phase-shift network" on the fixed delay is taken as a polarity inversion (deep notches
  where the sweep crosses 12.5 ms).
- RANDOM: the 820 Hz ±1 random walk is replaced by doubly low-passed noise (1 Hz) whose rate of change
  roughly matches the SSB slope, kept within the 2.5–22.5 ms limits.
- Feedback EQ corners (250 Hz / 3 kHz, ±12 dB) are guessed from the network's look; the manual's
  "Feedback Equalization Frequency Response" page is not in these PDFs.
- MIX is an addition (the unit is 100 % wet; it was used on a send).
- Left out: the dbx 303 compander pair (it hides converter noise a DelayNode doesn't have),
  the KEYBOARD and CV+MAN control modes, the tape capstan drive and the IEEE-488 remote.

## Roadmap

- KEYBOARD control mode: a CV / pitch input jack, so a synth (or the MIDI keyboard) plays the ratio,
  including "no key = freeze delay change".
- REVERSE / EXTEND details from the operating manual if it turns up.
- LED level meter with the reversed display in REPEAT.
