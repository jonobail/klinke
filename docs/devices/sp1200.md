# SP-1200

Sampling drum machine. Sources:

- _SP-1200 Owner's Manual_ (archive.org `synthmanual-emu-sp-1200-owners-manual`): §1C–1F performance
  module (8 pads, 4 banks, sliders for mix or tune / decay, ± a fifth), §1M output channels and
  their filtering, §1N channel ripoff, Part 4 sampling (SAMPLE 1–9: VU, preamp +00/+20/+40 dB,
  threshold, length 0.1–2.5 s in 0.1 s steps, armed / forced sampling, "Sample is good" /
  "Sample Overload"), §4E four 2.5 s memory zones, §4G erase, §4H truncation and looping.
- github.com/Lytrix/EMU-SP1200 (hardware notes): 26.04 kHz sample clock, 12-bit words, pitch by
  skipping (+) or doubling (−) samples. The repo's service-manual PDFs are Git LFS objects that
  weren't downloadable, so nothing here comes from them.

Code: `core/sp1200.ts` (maths, tested in `tests/sp1200.test.ts`), `audio/sp1200-unit.ts`, the panel
in `gear/sp1200-panel.*`. The MULT (`mult` in `core/gear.ts`) exists so a source can feed both its
usual chain and SAMPLE IN.

## Front panel

Laid out like the original (15 × 12 cells, about 1.2 : 1): SET-UP, DISK, SYNC and SAMPLE modules
along the top with their printed function lists, MASTER CONTROL on the right (display, Tempo / ◀ /
▶ / Enter, MIX and METRONOME VOLUME, keypad 1–9 and 0 with NO under 7 and YES under 9, Tap/Repeat,
Run/Stop, Record/Edit), PROGRAMMING, and PERFORMANCE (mode button, eight sliders, bank button,
eight pads). SAMPLE IN and MIX OUT are the jacks at the bottom corners.

As in the manual, press a module's button (its LED lights), then key a function number:

| Keys                                      | Function                                                                                                                                                                                                              |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SAMPLE                                    | VU mode: location, preamp, free time; VU meter (SAMPLE 1)                                                                                                                                                             |
| SAMPLE 2                                  | Assign voice: press a pad for the location, key 1–8 (or ◀ ▶) for its output channel                                                                                                                                   |
| SAMPLE 3                                  | Preamp +00 / +20 / +40 dB with ◀ ▶                                                                                                                                                                                    |
| SAMPLE 4                                  | Threshold with slider 1                                                                                                                                                                                               |
| SAMPLE 5                                  | Sample length with slider 1 or ◀ ▶ (0.1 s steps)                                                                                                                                                                      |
| SAMPLE 6 / 7 / 9                          | Re-sample (as last time) / arm (threshold) / force sampling                                                                                                                                                           |
| SAMPLE again, or Run/Stop, while sampling | Stop sampling                                                                                                                                                                                                         |
| SET-UP 17                                 | Channel assign: pad for the sound, 1–8 (or ◀ ▶) for the channel                                                                                                                                                       |
| SET-UP 18                                 | Decay/tune select: 1 tune, 2 decay                                                                                                                                                                                    |
| SET-UP 19                                 | Loop/truncate: sliders 1–2 start coarse / fine, 3–4 end, 5–6 loop length (§4H); the display shows S= E= L= in samples; Enter asks "Make Truncation Permanent?" (YES trims and frees memory, NO keeps the whole sound) |
| SET-UP 20                                 | Delete sound: YES deletes the selected location                                                                                                                                                                       |
| Performance mode button                   | TUNE/DECAY → MIX → MULTI MODE (multi mode not built: the sliders act as MIX)                                                                                                                                          |
| Bank button                               | A → B → C → D (four LEDs)                                                                                                                                                                                             |

Enter (or SAMPLE 1) returns to VU mode. Pads play and select the location everywhere.
Visibly present but answering "not yet" on the display: the other SET-UP functions, DISK, SYNC
(internal only), the PROGRAMMING buttons, Tempo, Tap/Repeat, Run/Stop (outside sampling),
Record/Edit and the metronome (its volume knob is stored but there's no click).

## Modelled

- 32 sound locations (A1–D8), 10 s of memory in four 2.5 s zones; a sound can't cross a zone.
- Sampling from the SAMPLE IN jack: preamp, GAIN trim, VU meter on the display, threshold-armed
  (ARM) or forced (FORCE) start, LENGTH limit, STOP; captured at 26.04 kHz / 12 bits into the
  selected pad's location (recording over a sound erases it). Overload is reported.
- Playback pitch by stepping the read address per 26.04 kHz tick with no interpolation (samples
  skipped or repeated), each value held until the next tick: the grit.
- Per sound: level (MIX sliders), tune or decay (TUNE/DECAY sliders, per the sound's DECAY MODE),
  output channel, START / END truncation, LOOP length (ends at END), TRIM (make permanent, frees
  memory), ERASE.
- Output channels: 1–2 dynamic filter (opens on each hit, closes as it decays), 3–6 fixed filter,
  7–8 unfiltered; one sound per channel (a new hit cuts the last); MIX VOLUME → MIX OUT.
- Pads play from the panel, the computer keyboard (A S D F G H J K = pads 1–8) and MIDI (the
  same keys relative to the keyboard's base C). Pressing a pad selects it for sampling / editing.

## Interpretation

- Bank A starts with a synthesised stand-in kit (KICK, SNARE, CL HAT, OP HAT, CLAP, TOM HI,
  TOM LO, RIM), made at 26.04 kHz / 12 bits; the real unit loads factory sounds from disk. B–D
  start empty.
- Filter frequencies (no service manual): input 12 kHz Butterworth; fixed channels two 9 kHz
  Butterworth stages; dynamic channels a resonant low-pass sweeping 13 kHz → 2.2 kHz with the
  sound's decay.
- The DECAY slider's centre is the sound's own length; down shortens it to 20 ms, up lengthens
  looped sounds up to 8×.
- The pad ↔ MIDI note map: the manual's Emax chart didn't survive OCR, so pads follow the
  computer keyboard's white keys.
- Sounds live in memory only (lost on reload), as on the hardware without a disk.
